# Getting help

| You want to… | Go to |
|---|---|
| Understand how a day or week was captured and rated | [How it works](docs/how-it-works.md) |
| Check that capture can run | `bb paper-trail doctor` and `bb paper-trail connectors --check` |
| Change what Paper Trail does | **Settings → Plugins → Paper Trail**, and the Settings tab inside Paper Trail |
| Ask a question or share a setup | [GitHub Discussions](https://github.com/vanZeben/bb-paper-trail/discussions) |
| Report a day or week rated wrong | [Open a "Rating feedback" issue](https://github.com/vanZeben/bb-paper-trail/issues/new/choose) |
| Report a bug | [Open a bug report](https://github.com/vanZeben/bb-paper-trail/issues/new/choose) |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) describes |
| Get help with bb itself | [getbb.app](https://getbb.app) |

Paper Trail is maintained in spare time, so answers can take a few days. If it's useful to you,
[sponsoring its development](https://github.com/sponsors/vanZeben) helps keep it going.
